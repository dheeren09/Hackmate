# 🧠 AI-Powered Quiz Generator

An intelligent quiz generation application designed to make learning and knowledge assessment more interactive, accessible, and efficient.

The application uses AI to generate quizzes dynamically, allowing users to test their knowledge through an interactive interface rather than relying on traditional static questionnaires.

## 🚀 Features

- AI-powered dynamic quiz generation.
- Interactive and user-friendly interface.
- Automatically generated quiz questions.
- Backend integration for processing requests.
- Google Gemini API integration.
- Real-time communication between frontend and backend.

## 🛠️ Tech Stack

| Component | Technology |
|---|---|
| Frontend | React.js |
| Styling | CSS |
| Backend | Backend API |
| AI Integration | Google Gemini API |
| Version Control | Git & GitHub |
